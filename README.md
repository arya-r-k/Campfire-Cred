# 🔥 Campfire – Student Community & Mentorship Platform

Campfire is a modern peer-to-peer technical learning, Q&A, and mentorship platform designed for tech schools and coding communities. It bridges the gap between students, peers, and Teaching Assistants (TAs) through gamified discussions, instant scheduling, and real-time credential tracking.

---

## ✨ Key Features

### 💬 1. Interactive Technical Q&A Feed
* **Tag Filtering & Search:** Filter discussions instantly by tags (e.g., `#React`, `#Node`, `#Python`) or search through technical threads.
* **Detailed Discussion View:** Click on any question to dive into a dedicated thread, view peer replies, and read code explanations.
* **Gamified Solutions:** Mark answers as verified solutions to reward community members with engagement credentials (`Creds`).

### 📅 2. TA & Peer-to-Peer Scheduling
* **1-on-1 Office Hours:** Seamlessly book dedicated mentorship slots with course Teaching Assistants or high-cred peers.
* **Instant Video Room Generation:** Automatically generates secure video session links upon booking confirmation.
* **Google Calendar Integration:** Includes a direct **"Add to Google Calendar"** action button in the confirmation modal, pre-filling event titles, participant details, and video links.

### 🏆 3. Real-Time Gamified Leaderboard
* **Dynamic Creds Tracking:** Earn `Creds` by asking questions (+50), providing answers (+15), and solving technical blocks.
* **Live Sorting:** Automatically merges your live profile with the global leaderboard and resorts standings in real-time.

---

## 🛠️ Tech Stack & Architecture

* **Frontend Framework:** React (Functional Components with Hooks `useState`, props management)
* **Styling & UI:** Tailwind CSS (Responsive layout, custom theming, card components)
* **Icons & Modals:** Custom modular UI wrapper components (`./components.js`)
* **Integrations:** Google Calendar Web URL Scheme API for direct event scheduling.
